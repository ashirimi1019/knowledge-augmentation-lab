02 · complete concept map

Choose the knowledge operation, not the trend.

Filter by family. “Advanced” and “agentic” are umbrellas; Self-RAG, CRAG, CAG, KAG, and database TAG have specific fidelity boundaries.

runnable

Naive RAG

Chunk → retrieve top-k → inject evidence → generate with citations.

Watch: retrieval errors flow directly into generation.

runnable

Advanced RAG

Transform queries, fuse retrievers, rerank, and filter.

Boundary: an umbrella, not one reproducible algorithm.

architecture

Modular RAG

Compose replaceable retrievers, routers, verifiers, memory, and generators.

Requires: typed contracts, traces, and disciplined configuration.

runnable

Hybrid RAG

Combine exact lexical ranking and vector-space ranking with RRF.

Lab: BM25 + transparent TF-IDF baseline.

architecture

Multi-hop RAG

Decompose and alternate retrieval with evidence accumulation.

Watch: error propagation and runaway loops.

paper-specific

Self-RAG

A trained model emits retrieval and reflection tokens.

Not: any generic prompt-based critique loop.

paper-specific

CRAG

Evaluate retrieval, refine knowledge, and use fallback sources.

Generic analogue: call it crag-inspired.

router

Adaptive RAG

Route no-retrieval, single-hop, or iterative retrieval by query complexity.

Watch: routing mistakes become a new failure mode.

umbrella

Agentic RAG

A bounded controller selects sources, observes, replans, and stops.

Requires: budgets, loop detection, and permissions.

teaching-scale

GraphRAG

Local graph evidence plus global community-level reports.

Lab: connected communities, not full Microsoft GraphRAG.

runnable mini-kag

KAG / KG-RAG

Use graphs, ontologies, rules, or schemas for explicit reasoning.

Boundary: OpenSPG KAG is a specific full stack.

runnable primitive

Table augmentation

Typed filters and calculations with row-level provenance.

Full TAG: combines DB and LM semantic operators.

simulator

CAG

Preload stable knowledge and reuse a model KV/prefix cache.

Lab: context reuse metrics, not fake past_key_values.

baseline

Long context

Place the corpus directly in context, with or without retrieval.

Watch: token cost and lost-in-the-middle effects.

runnable

Memory augmentation

Read and write scoped state across interactions.

Requires: provenance, correction, TTL, and deletion.

runnable

Tool augmentation

Call allowlisted APIs, search, calculators, code, or SQL.

Rule: retrieved text never grants tool authority.

extension

Multimodal RAG

Retrieve across text, images, audio, video, tables, and layout.

Requires: modality-specific provenance and evaluation.

03 · engineering honesty

Claims should match the mechanism.

The project deliberately avoids tutorial theater: no API key is needed, TF-IDF is not called a semantic model, and a cached string is not called a model KV cache.

✓Source trust and ACLs run before ranking.
✓Both RAG answers retain evidence IDs and a decision trace.
✓Teaching simulations are separated from faithful paper reproductions.
✓Retrieval and lexical answer groundedness are executable; wider evaluation layers are documented.
